# 전동기 탐구 실험실 (영구자석 동기전동기 인터랙티브 시뮬레이터)

중3~고1 학생이 직접 조작하며 전동기 원리를 발견하도록 만든 학습 도구입니다. 서버 없이 브라우저에서 실행됩니다.

## 실행 방법
1. 이 폴더(`3_out`)의 `index.html`을 더블클릭해 크롬/엣지로 엽니다. (인터넷 불필요, 외부 라이브러리 없음)
2. 주소 끝에 `#4`처럼 붙이면 해당 단계로 바로 열립니다.
3. 파일 구성: `index.html`, `style.css`, `js/core.js`(공통 도구), `js/step1~7.js`(단계별), `js/main.js`.

## 단계별 사용 안내
| 단계 | 하는 일 | 확인할 것 |
|---|---|---|
| 1 자석의 성질 | 자석 B를 끌거나 슬라이더로 이동, A·B 뒤집기 | 같은 극=척력, 다른 극=인력, 자기력선(N→S) |
| 2 전자석 | 전류 켜기/끄기, 방향 바꾸기, 세기 조절 | 오른손 법칙, 극성 반전, 끄면 자기장 소멸(나침반) |
| 3 힘과 회전력 | 전자석 극성·전류·회전자 각도 변경, 놓아 보기 | 힘이 있어도 정렬되면 토크 0, 고정 전자석은 회전자를 멈춰 세움 |
| 4 회전 자기장 | 재생/정지, 방향, 주파수, 세기, 극쌍 수 | U·V·W 120° 위상차, 합성 자기장 크기 일정·방향 회전, rpm = 60f/극쌍 수 |
| 5 속도와 부하 | 부하·전류·주파수 조절, 초기화 | 한계 내에서는 속도 유지(부하각 증가), 한계 초과 시 탈조 |
| 6 역기전력 | 회전 속도, 약계자 제어 켜기/끄기 | 속도↑ → 역기전력↑, 약계자로 유효 자속↓, 최대 토크 변화 |
| 7 정리 | 흐름도, 학습 목표 체크, 종합 퀴즈 6문항 | 전체 연결 |

모든 단계 공통: ① 예측 고르기 → 실험 → “예측 확인하기”, ② 🤔 왜 그럴까요?, ③ 핵심 정리, ④ 이해도 퀴즈(오답 시 힌트), ⑤ 용어 옆 `?` 버튼과 📖 용어 사전.

## 학생용 핵심 개념 정리
- 자석의 같은 극은 밀어내고 다른 극은 끌어당깁니다.
- 전류가 흐르는 코일은 전자석이 됩니다. 전류 방향이 바뀌면 N·S극이 바뀝니다(오른손 법칙).
- 힘이 회전축에서 어긋난 방향으로 작용할 때 회전력(토크)이 생깁니다. 정렬되면 토크는 0입니다.
- 3상 교류(120° 시간차)로 합성 자기장이 일정한 크기로 회전하고, 회전자가 따라 돕니다.
- 빨리 돌수록 역기전력이 커집니다. 약계자 제어는 d축 전류로 유효 자속을 줄여 이를 낮춥니다(영구자석의 극은 바뀌지 않음).

## 탐구 활동(교사용 질문 예)
1. 같은 극을 마주 보게 한 뒤 거리를 줄이면 힘은 어떻게 변할까? (1단계)
2. 전류를 2배로 하면 자기장 세기는? (2단계, 상대값 60%→100% 비교)
3. 회전자를 180°에 두면 힘이 있는데도 왜 토크가 0일까? (3단계)
4. 극쌍 수를 1→2로 바꾸면 같은 주파수에서 속도는? (4단계)
5. 부하를 15, 35 N·m로 올리면 각각 무슨 일이? (5단계)
6. 10000 rpm에서 약계자 OFF/ON의 역기전력과 최대 토크를 비교하라. (6단계)

## 물리 모델의 가정과 한계 (화면에도 표시됨)
- **1단계**: 자석을 양 끝 점극(자극 모델)으로 단순화, 힘은 상대값(1/r²). 실제 자석은 모양·재질에 따라 다름.
- **2단계**: 잔류 자기를 무시한 이상 코일. 자기장 선은 “양 끝에 극이 있는 막대자석” 등가 모델, 세기는 전류에 비례하는 상대값.
- **3단계**: 고정자 전자석이 회전자 위치에 균일 자기장을 만든다고 가정, 토크 ∝ 전류 × sin(각도차). 놓아 보기는 감쇠 포함 단순 동역학.
- **4단계**: 합성 자기장은 세 상 전류 × 축 방향 벡터의 실제 합. 회전자는 합성 자기장보다 전기각 30° 뒤에서 동기로 돈다고 고정(부하 반응은 5단계). 애니메이션은 슬로모션이며 수치(Hz, rpm)는 실제 기준.
- **5단계**: 극쌍 2, 토크상수 8 N·m/A, 관성 0.5 kg·m², 자기장 가속 120 rpm/s의 개루프(위치 피드백 없음) 모델. 진동 가라앉힘용 교육용 감쇠 항 포함. 실제 전기차는 회전자 위치를 측정해 자기장을 맞추므로 이렇게 쉽게 탈조하지 않음.
- **6단계**: 표면부착형 PMSM(Ld=Lq), 저항·철손·포화 무시, 극쌍 4, 영구자석 자속 0.12 Wb, 인덕턴스 0.4 mH, 전류 한도 250 A, 배터리 400 V(상전압 한계 400/√3 ≈ 231 V)의 교육용 예시값. 최대 토크 = 1.5·p·영구자석 자속·q축 전류(q축 전류는 전압·전류 한계 중 작은 값). 고속에서 토크가 줄어드는 이유는 d축 전류에 전류를 쓰고 전압 여유가 줄어 q축 전류를 흘리기 어려워지기 때문(유효 자속 자체가 토크를 정하는 것이 아님). 약계자 ON은 한도 안에서 최대 토크가 되는 d축 전류를 자동 선택하는 단순 제어이며, MTPA·열 한계·실제 인버터 제어를 모두 구현하지 않음. 약계자 제어가 항상 속도·토크를 높이는 것은 아니며, 낮은 속도에서는 효과가 없고 높은 속도에서는 최대 토크가 줄어듦을 그래프로 확인할 수 있음.
- 진도(퀴즈 통과 체크)는 새로고침하면 초기화됩니다(저장하지 않음).
